# Remote maintenance protocol — 0.3.0 household pilot

Parent GET `/api/parent/companion/commands?childId=<uuid>` -> `{devices:[{id,name,version,last_seen_at}],commands:[{id,client_id,kind,status,created_at,expires_at,completed_at,result}]}` newest20. Parent POST same path `{clientId,kind,requestId:UUID}` -> `{ok:true,id}`. Client belongs to logged-in parent's family; backend derives child. Replay same requestId must return samecommand, changed target/kind rejects409. Kinds exactly `diagnostics`, `check-update`, `test-countdown`, `apply-update`. No user-defined command arguments, scripts or executables. At most one unfinished command perdevice/kind; queuedcommands expire in10min.

Device GET `/api/companion/v2/commands` authenticated bearer -> `{command:null|{id,kind,expiresAt}}`. Atomic claim oldestqueued setsrunning; existingrunning redelivered until ack. Expired commands markexpired. One command at a time. Device POST same endpoint `{id,status:'completed'|'failed',result:{...}}` acknowledges. Allowed result keys only: `version` string<=30, `platform` string<=30, `policyRevision` integer>=0, `policyAgeSeconds` integer>=0, `familyEnabled` boolean, `gamingAllowed` boolean, `reason` string<=200, `updateOutcome` enum `current|staged|failed|not_checked|deferred|restart_requested`, `updateStatus` string<=200, `countdownOutcome` enum `requested|displayed|unavailable`, `errorCode` string<=80. No tokens, paths, username, browsing records or raw stack traces. Wholebody <=4096bytes. Other keysreject. Server accepts terminalrepeat iff identicalstored status+result; changedreplay rejects409. Completedresult must not imply checksnotactuallyperformed.

Remote diagnostics report current app/policy/update health; not a real game-closure or nativefilter proof. Checkupdate runs existing signedrelease check/stage; completedcommand means check completed, not softwareinstalled. Countdown is a labelled10sectest; no debit, policychange or gameclose. Any interactiveeffect is deduped bycommandid; save result before ack. If test is merely requested not provenvisible use requested, notdisplayed. Child should see transparenttestlabel.

Parent sees queued/running/completed/failed/expired separately. Offlinecommands waituntil reconnect orexpiry. No remote arbitraryshell. Existing updater's signature/rollback and sameorigin/HTTPS guards remain. Currentpeer app remainscooperative; initialinstaller peruser setup isn'tprotectedservice. Publichosted distribution, adminservice, Authenticode and fullnativefilter are not claimed.

Apply-update requests a controlled restart into an already signature-verified staged build. Defer while any classified same-user game is running, including minimizedgames. Durableledger andcommandreceipt before restart. If legacylauncher cannot support remoteactivation return explicit failure/installnewpackageinstruction. Acknowledgement may say restart_requested; only later deviceheartbeat verifiesactualinstalled version. Never closegames to applyanupdate. The stablelauncher keeps startuphealth rollback.
